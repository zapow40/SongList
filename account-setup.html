To finish setup, paste the deployed Google Apps Script web app URL into this site's config file:

site/assets/auth-config.js

  1. Deploy the google-apps-script project as a web app.
  2. Copy the URL ending in /exec.
  3. Open auth-config.js and paste it between the quotes after googleAppsScriptWebAppUrl:.
  4. Upload the updated site folder again. Team sign-in and Admin sign-in will then open your Google account portal.
